# Убийство процессов разработки

Этот проект содержит два скрипта для поиска и убийства процессов, связанных с командой `npm run dev` (которая запускает `next dev`):

## Bash-скрипт (kill-dev-process.sh)

### Использование

```bash
./kill-dev-process.sh
```

Или через npm:

```bash
npm run kill-dev
```

### Функциональность

- Ищет процессы, содержащие 'next dev' или 'npm run dev'
- Отображает найденные процессы
- Убивает каждый найденный процесс сначала с помощью SIGTERM, а затем при необходимости с помощью SIGKILL

## Node.js-скрипт (kill-dev-process.js)

### Использование

```bash
node kill-dev-process.js
```

Или через npm:

```bash
npm run kill-dev-js
```

### Функциональность

- Поддерживает как Unix-системы (Linux/macOS), так и Windows
- Ищет процессы, связанные с 'next dev', 'npm run dev' или 'yarn dev'
- Убивает найденные процессы сначала с помощью SIGTERM, а затем при необходимости с помощью SIGKILL

## Установка

Оба скрипта уже добавлены в package.json как npm-скрипты:

- `npm run kill-dev` - для запуска bash-скрипта
- `npm run kill-dev-js` - для запуска Node.js-скрипта

## Примечания

- Bash-скрипт рекомендуется использовать на Unix-системах (Linux/macOS)
- Node.js-скрипт обеспечивает кроссплатформенную совместимость
- Оба скрипта безопасно завершают процессы, позволяя им корректно освободить ресурсы
- При необходимости скрипты используют принудительное завершение (SIGKILL/KILL)
